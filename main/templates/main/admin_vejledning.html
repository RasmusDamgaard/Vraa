Admin Vejledning

Denne side forklarer, hvordan du administrerer Vraa-hjemmesiden som administrator.

ⓘ
Bemærk: Denne side er kun synlig for brugere med administratorrettigheder.

1. Oversigt

Som administrator har du ansvar for at:

  • Godkende nye brugere
  • Godkende eller afvise bookinger
  • Moderere beskeder og kommentarer ved behov
  • Hjælpe brugere med problemer (f.eks. nulstille adgangskoder)

2. Adgang til Admin

Django Admin er administrationspanelet, hvor du kan håndtere alle data på hjemmesiden.

Åbn Admin-panelet

  1. Gå til /admin/
  2. Log ind med dit brugernavn og adgangskode
  3. Du ser nu en liste over alle datatyper, du kan administrere

Navigation i Admin

Sektion Indhold
Users Brugere og deres konti
Bookings Alle bookinger (afventende, godkendte, afviste)
Messages Beskeder på beskedtavlen
Comments Kommentarer til beskeder

3. Brugerhåndtering

Godkend en ny bruger

Når en ny bruger registrerer sig, er deres konto inaktiv indtil godkendelse.

  1. Gå til Admin → Users
  2. Find brugeren (inaktive brugere har ikke flueben ved “Active”)
  3. Klik på brugernavnet for at åbne detaljer
  4. Sæt flueben ved Active
  5. Klik Save
💡
Tip: Du kan godkende flere brugere på én gang:
  1. Sæt flueben ved de brugere, du vil godkende
  2. Vælg “Activate selected users” fra dropdown-menuen
  3. Klik Go

Deaktiver en bruger

  1. Gå til Admin → Users
  2. Klik på brugernavnet
  3. Fjern fluebenet ved Active
  4. Klik Save

Deaktiverede brugere kan ikke logge ind, men deres data bevares.

Nulstil en brugers adgangskode

  1. Gå til Admin → Users
  2. Klik på brugernavnet
  3. Klik på linket ved “Password” (typisk “this form”)
  4. Indtast den nye adgangskode to gange
  5. Klik Change password

Gør en bruger til administrator

  1. Gå til Admin → Users
  2. Klik på brugernavnet
  3. Under “Permissions”, sæt flueben ved:
    • Staff status — giver adgang til admin-panelet
    • Superuser status — giver fuld adgang (valgfrit)
  4. Klik Save

4. Bookinghåndtering

Se alle bookinger

  1. Gå til Admin → Bookings
  2. Du ser en liste over alle bookinger med status, bruger og datoer

Filtrer bookinger

Brug filterpanelet i højre side til at filtrere efter:

  • Status — pending, confirmed, rejected, cancelled
  • Bruger — se bookinger fra en specifik bruger
  • Dato — filtrer efter oprettelsesdato

Godkend en booking

  1. Gå til Admin → Bookings
  2. Klik på den booking, du vil godkende
  3. Skift Status til Confirmed
  4. Klik Save

Afvis en booking

  1. Gå til Admin → Bookings
  2. Klik på bookingen
  3. Skift Status til Rejected
  4. Klik Save
⚠
Vigtigt: Systemet forhindrer automatisk dobbeltbookinger. Du kan ikke godkende en booking, der overlapper med en allerede godkendt booking.

Booking-statusser

Status Betydning Vises i kalender
Pending Afventer godkendelse Ja
Confirmed Godkendt booking Ja
Rejected Afvist af administrator Nej
Cancelled Annulleret af brugeren Nej

5. Indholdsmoderation

Rediger en besked

  1. Gå til Admin → Messages
  2. Klik på beskeden
  3. Rediger indholdet efter behov
  4. Klik Save

Slet en besked

  1. Gå til Admin → Messages
  2. Klik på beskeden
  3. Klik Delete nederst på siden
  4. Bekræft sletningen

Når du sletter en besked, slettes alle tilhørende kommentarer også.

Slet en kommentar

  1. Gå til Admin → Comments
  2. Find og klik på kommentaren
  3. Klik Delete
  4. Bekræft sletningen

6. Fejlfinding

En bruger kan ikke logge ind►

Tjek følgende:

  1. Er brugeren oprettet? Kig i Admin → Users
  2. Er kontoen aktiv? Tjek at “Active” er markeret
  3. Nulstil adgangskoden, hvis brugeren har glemt den
Kalenderen viser ikke bookinger►

Kalenderen viser kun bookinger med status “pending” eller “confirmed”.

Tjek i Admin → Bookings, om der findes bookinger, og hvad deres status er.

Jeg kan ikke godkende en booking (dobbeltbooking)►

Systemet forhindrer dobbeltbookinger. Hvis du ikke kan godkende en booking:

  1. Tjek om der allerede er en godkendt booking i samme periode
  2. Afvis eller annuller den overlappende booking først
  3. Prøv igen at godkende den ønskede booking
Siden er langsom eller viser gammelt indhold►

Hjemmesiden bruger caching for at forbedre hastigheden. Noget indhold kan være op til 1 time gammelt.

Prøv at genindlæse siden (Ctrl+F5 eller Cmd+Shift+R) for at hente det nyeste indhold.

Jeg har brug for teknisk hjælp►

Ved tekniske problemer, der ikke kan løses via admin-panelet:

  • Kontakt den person, der vedligeholder hjemmesiden
  • Beskriv problemet så detaljeret som muligt
  • Inkluder eventuelle fejlmeddelelser

Har du brug for yderligere hjælp? Kontakt den tekniske ansvarlige for hjemmesiden.
